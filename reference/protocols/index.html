协议配置字段

协议配置字段

八种协议各自的参数、可承载的内核与安全模式，按声明表逐一列出。

在哪里：网络 › 节点 › 协议配置

怎么用

  1. 按协议选可承载内核，再核对安全模式；表中内核从左到右是偏好序，不表示可同时承载。
  2. 打开协议子页核对参数。客户端感知的参数改变后，客户端也须更新连接材料。
  3. 协议参数、传输参数与安全材料分别填写，不能把用户凭据当作任意协议参数添加。

字段

协议 内核偏好序 安全模式（首项为默认） 分享链接前缀 每用户凭据材料
VLESS xray、sing-box none、reality、tls vless UUID
Shadowsocks sing-box、xray 无 TLS 层 ss 128 位与 256 位两份用户 PSK
Snell v5 sing-box 无 TLS 层 snell 用户密钥
Snell v6 sing-box 无 TLS 层 snell 用户密钥
mieru mbox 无 TLS 层 mierus mieru 密码
AnyTLS sing-box reality、tls anytls AnyTLS 密码
NaïveProxy sing-box tls naive+https NaïveProxy 密码
SOCKS5 sing-box、xray、mbox 无 TLS 层 socks5 SOCKS5 密码

公共参数

tcp_fast_open

可选，取值 true / false，默认 true。客户端感知：否。

控制服务端传输控制协议监听套接字的快速打开，不是客户端连接方式。除 mieru 外，七种协议都读取此项；mieru 使用自己的套接字，不接受这个不会生效的参数。

sniffing

可选，取值 true / false，默认 true。仅 xray 的 VLESS 读取。客户端感知：否。

控制入站目标嗅探与目标覆盖。sing-box 已移除入站嗅探字段，mbox 复用其渲染器；xray 的 Shadowsocks 与 SOCKS5 渲染器也不读取这个开关，不能给这些配置添加同名参数。

注意

  • 参数不是任意键值容器：未被对应协议读取的键会被拒绝，内核专属字段也不能移到其他内核。
  • fanout、port_count、tls_per_node 的准入来自协议特性，不属于各子页逐项列出的普通参数；按端口扇出、端口数量和逐服务器证书只在相应特性存在时可用。
  • 没有 TLS 层不等于协议都没有自身加密；SOCKS5 本身不加密，其他协议的限制分别见子页。
