VLESS

VLESS

一个用户一个 UUID 的 TCP 协议，可裸跑、走 REALITY 或走 TLS；xray 优先承载，sing-box 也能。

内核：xray（优先）、sing-box 安全模式：无、REALITY、TLS 传输：tcp、ws、httpupgrade、xhttp（默认 tcp） 分享链接：vless://

怎么用

  1. 选择 xray 或 sing-box，选择安全模式与传输；默认不加安全层，不能把默认值理解为已加密。
  2. 使用 xtls-rprx-vision 时只选 tcp，安全模式选 reality 或 tls。
  3. 使用 xray 的协议层加密时，同时填入服务端与客户端两份材料；修改客户端感知字段后更新订阅。

字段

flow

可选，取值为空或 xtls-rprx-vision，默认空。客户端感知：是。

同一协议配置的用户共用此值。非空时要求 tcp 传输并启用 TLS 或 reality；封装传输不能提供它需要的原始 TLS 连接。两个内核都接受此字段，但不能混用非空与空值的客户端配置。

decryption

可选，默认空，仅 xray。客户端感知：否。

协议层加密的服务端材料，必须与 encryption 成对填写。空值或 none 表示关闭；关闭时 xray 配置仍会写入 none，sing-box 没有对应字段。材料由 xray vlessenc 成对生成，不能从其中一份推导另一份。

非空值使用 mlkem768x25519plus，第二段取 native / xorpub / random，第三段是会话票据时长，如 600s 或 0-900s；密钥段解码后须为 32 或 64 字节。

encryption

可选，默认空，仅 xray。客户端感知：是。

与 decryption 配对的客户端材料，会进入分享链接。空值或 none 表示关闭。非空串第三段须为 0rtt 或 1rtt，不是服务端的时长；把服务端串复制到这里会被拒绝。算法、第二段与密钥长度的要求同上。

tcp_fast_open

本协议读它，含义见总页。xray 与 sing-box 都读取。

sniffing

本协议读它，含义见总页。仅 xray，sing-box 不接受此参数。

传输字段

这些字段属于单独的传输配置，不放入协议参数。

字段 必填 默认 说明
type 否 tcp 空值与 raw 都归一为 tcp；ws、httpupgrade 两核均可，xhttp 仅 xray
path 否 / 仅三个封装传输；须以 / 开头，不得包含 ? 或 #
host 否 空 仅三个封装传输；预期的 Host 请求头
early_data 否 0 仅 ws；提前数据字节数，上限 8192，零为关闭
mode 否 auto 仅 xhttp；取 auto / packet-up / stream-up / stream-one

tcp 不接受上述路径、请求头、提前数据与上传模式。ws 与 httpupgrade 只允许无安全层或 TLS；tcp 与 xhttp 还可选 reality。

注意

  • 协议层加密与 TLS 是两层设置：加密材料仅 xray 支持，不能因传输被两核支持就将同一材料切给 sing-box。
  • 提前数据的两端表示不同：sing-box 使用字节数与固定请求头 Sec-WebSocket-Protocol，xray 客户端在路径附加 ?ed=N；不要手工把该查询串填入服务端 path。
  • xhttp 没有 sing-box 与 mihomo 客户端投影，生成这两类订阅时会跳过，而不是输出无法使用的节点。
