weirctl 与 API 令牌

weirctl 与 API 令牌

weirctl 是面板的命令行客户端，用 API 令牌登录；契约与字段以它的 describe 为准。

在哪里：系统 › 设置中创建 API 令牌；命令在本机终端执行。

  • 用与面板配套的 weirctl；version、methods、describe 不连接面板。weirctl skill list 查看内嵌操作指南，weirctl skill export --to <目录> 安装指南；同名文件内容不同时整体拒绝，明确覆盖才加 --force。
  • 登录使用下面的文件入口，或从标准输入、WEIRCTL_TOKEN 读取令牌，不把令牌写进命令行参数。登录先验证身份再保存本地配置；随后用 whoami 核对身份、上限、范围和有效期。
weirctl login --url https://panel.example.com --token-file /私有目录/令牌
weirctl whoami
weirctl methods
weirctl describe <方法名>
  • --profile 选择本地登录配置，缺省先取 WEIRCTL_PROFILE，再取 default。WEIRCTL_URL 与 WEIRCTL_TOKEN 须同时提供才能整体覆盖它。请求涉及认证或契约标记的秘密字段时，只能用 -d @<文件> 或 -d -；不因实际未填秘密而允许行内请求体。
  • 创建、列出和按标识管理令牌须在交互式控制台会话完成。weirctl token inspect 只读当前令牌元数据；weirctl token revoke-self --confirm-destructive 只吊销当前令牌，不删除本地登录配置。令牌上限再高也不能替代要求交互式会话的凭据。
  • 标准输出只放应答，错误对象在标准错误中；不要合并两者。退出 0 为成功，1 为其他失败，2 为命令或契约输入错误，3 为参数错误，4 为未找到，5 为已存在或并发冲突，6 为前置条件不满足，7 为无权调用，8 为认证失败，9 为暂时不可用或超时，10 为等待条件超时，11 为资源耗尽。9 可退避重试；8 重新登录；契约修订不匹配的 6 必须换配套版本；其他码先按错误内容修正，不原样重试。
