接入第一台服务器

接入第一台服务器

把一台你自己的机器加进面板：在面板上建一行服务器，把安装命令交给机器，等它上线。

先选接入方式

用平台管理员身份进入网络 › 服务器 › 新增服务器。页面有「批量接入」与「单台接入」两个页签。第一台机器选单台接入，方便指定名称并跟踪它；批量接入使用同一发现令牌接多台机器，名称由面板分配。

先查看上方「Agent 二进制托管」的状态。未托管时创建按钮不可用，点击「拉取本版 agent」，等状态变为「已就绪」。安装脚本只安装本面板验过签名的节点程序。

继续阅读：接入与安装命令。

建立服务器行

在单台接入页填写服务器名称，点击「创建」。名称供人辨认，不参与路由或准入，但必须唯一。创建前先检查列表：若这台机器已有等待接入的行，或有准备复用的已解绑行，不要重复创建。

创建成功会显示安装命令、接入令牌和有效窗口。普通登录账户使用默认带提权的命令；已经是 root 的终端勾选「屏蔽 sudo」换成不带提权的形态，不必为了换一种命令再建一行。

继续阅读：服务器。

在机器上运行命令

将命令交给负责安装这台机器的人，在目标机器终端运行。命令内含接入凭据，只给装机者，不放进公开聊天、工单或运行记录。明文只显示一次，离开页面后不能再查看。

命令过期或丢失时，到同一服务器详情的「接入令牌」重新生成；不要重新建服务器行。批量接入重新生成发现令牌会立即作废旧令牌，尚未安装的机器必须改用新命令。

继续阅读：地址与域名。

等待上线并核对

安装成功后回到页面查看新上线的服务器，或进入服务器详情核对：

看哪里 完成条件 未达到时怎么读
详情页头的徽标 「在线」 「离线」：已绑定不等于现在在线；节点程序起不来时页头会写出最近一次启动失败的原因
「接入令牌」面板的「绑定机器」 显示机器指纹的前 16 位 「未绑定」是机器还没装好或没连上来；「已解绑机器（时刻）」是已解绑，行与引用仍保留，重新生成接入令牌、用新安装命令重新绑定
「运行时」面板 节点程序版本与各内核版本已上报，平面看板没有失败项 缺某个内核时，需要它的协议不能部署到这台机器；点「推送 →」转到「命令」页签，在「推送 Proxy Core」里选内核后点「推送到本服务器」，约一分钟后这里显示版本

控制连接注册且最后心跳在窗口内才算在线；程序每 5 秒发一拍，窗口为 20 秒。绑定、在线与指纹都符合，这台机器就接进来了；某个节点有没有真的在这台机器上跑起来，看节点页那一行的应用态，不看这里。

继续阅读：面板与机器两个平面。

准备承载节点

刚上线而没有任何节点是正常状态。继续查看已安装代理内核和端口池：所选协议所需内核必须已上报，否则不能创建对应部署；自动分配端口要看余量 free，不能自行用总量减已占推算。

端口池总量为零表示尚未声明范围；总量大于零而余量为零才是池内无可分配端口。已占统计还包括池外占用和机器程序自用端口，因此新机器的已占不必为零。

继续阅读：协议与内核。
