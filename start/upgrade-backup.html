升级与备份

升级与备份

面板与节点各自怎么升级、备份放在哪里、换机器时许可怎么带走。

在哪里：系统 › 设置 › 备份与通知；面板更新在设置页的面板版本区域。

升级与保留数据

  • 升级前先导出备份，并核对目标发布的升级前提；旧库不一定能直接升到任意版本，数据库比程序新时也不能直接降级打开。
  • 面板只承载落后目标发布不超过 3 个 schema 版本的库：更老的库启动会被拒绝，并提示先用哪个 schema 版本区间内的中间发布升一次；按发布说明里的「schema N」挑区间里最新的那个中间发布先升，再升到目标发布。schema 95 的发布（v1.0.3-dev.24）及更早的发布能把任何更老的库一次带到自己的版本。备份归档导入受同样限制，先在中间发布上导入并启动，再导出给目标发布。
  • 在面板版本区域点击「检查更新」，确认目标后点击「立即更新」。面板会替换自身、同步节点程序产物并重启；服务器上的节点程序仍须到服务器列表单独推送。若产物同步失败，先补齐再推送，避免机器拿到旧版本。
  • 备份与迁移区域的「导出备份归档」下载数据库快照、证书颁发机构口令与 panel.conf 参考副本；归档等同面板全部机密，必须按私钥保管和传输。
  • 恢复时，在目标机安装同版本面板并停止服务，再执行 weir-panel backup import 归档文件；配置副本是迁移参考，不应把旧机监听地址直接视为新机可用地址。
  • 换机迁移已激活许可时，旧安装停用后保存迁移码，在替代安装兑换；备份里的旧许可身份不会使已停用席位重新有效，迁移码也不要放进备份说明或公开记录。
