用户

用户

用户页管每一个用户账号：套餐、节点可见性、设备、用量、账本与安全设置。

隧道设备展开后逐个显示身份的 IPv4 与 IPv6 隧道地址；入口不承载 IPv6 时只显示 IPv4，不显示空地址占位。

在哪里：运营 › 用户 › 详情 › 概览 / 套餐管理 / 可用服务器 / 线路 / 公共节点 / 隧道设备 / 用量明细 / 计费流水 / 安全

怎么用

  1. 在用户列表点「新建用户」，向导依次是账户信息、套餐、服务器范围、交付包四步。
  2. 账户信息一步填用户名与初始密码，再把账户到期时间改到你要的时刻。
  3. 套餐一步选一份或多份套餐模板，每份模板随账号建一份套餐；一份都不选，账号建成后订阅为空，服务器范围一步随之跳过。
  4. 服务器范围一步列出所选模板此刻覆盖的服务器，核对后按「创建」。
  5. 交付包里的分发信息含登录密码与订阅链接，复制发给用户。
  6. 以后改套餐、查用量、轮换凭据，点用户名进详情页，在对应页签里做。

字段

用户列表

字段 必填 默认 说明
用户名 只读 — 平台管理员带「管理员」徽标，分销商管理员带「分销商管理员」徽标；联邦用户名旁有「镜像」限定语。顶部筛选框只按用户名过滤。
套餐用量 只读 — 「N 套餐 · 最紧余量 X%」：在服务中的有限额套餐里余量最少的那一份；全部不限额时显示 ∞。暂停或到期的套餐不参与。
历史流量 只读 — 网卡口径的入、出、总，从不清零；与计费已用不是同一个数。
状态 只读 — 本面板对账号的裁决（启用 / 停用）；被上游面板拒收时另挂一枚徽标。
账户到期 只读 — 账户本身的到期，与套餐到期互不影响。
套餐到期 只读 — 生效中套餐里最早的到期时间与倒计时；全部永久时显示「-」。
最后使用节点 只读 — 最近一次有流量的节点：成品实例的线路写「成品节点 · 成品名」；服务器上的协议面写「服务器名 · 协议配置名」；只认得出机器时写「服务器 · 机器名」。名字已删时退到 id，整段没有就省略。
最后使用时间 只读 — 最近一次有流量的时刻。

新建用户

字段 必填 默认 说明
用户名 是 无 登录门户用的名字。
初始密码 是 无 「随机生成」给出 12 位密码，大小写字母、数字、特殊字符各至少一个。
角色 是 普通用户 普通用户或分销商管理员。只在平台管理员登录且分销商子系统开着时出现。
所属分销商 分销商管理员必填 无 用户归哪个分销商；与角色同现同隐。
备注 否 空 只在控制台可见，不进门户、不进订阅。
账户到期时间 普通用户必填 下一个整点 控制数据面接入的寿命；可勾「账户永不过期」。须晚于当前时间。分销商管理员没有这一项。
套餐模板 否 不选 可多选，每份模板各建一份跟随该模板的套餐。只有普通用户、且落在操作者自己的分销商里时才有这一步。
套餐到期 选了模板时必填 与账户到期同刻 对本次建的全部套餐生效；改动后不再跟随账户到期。

概览

字段 必填 默认 说明
套餐摘要 只读 — 套餐总数与生效中的份数、账户到期、网卡口径的历史流量。有未归账流量时显示琥珀徽标「未归账流量」。
最后在线 只读 — 最近一次有流量的时刻，与用户列表的「最后使用时间」是同一个数；从未有流量写「从未」。
最后使用节点 只读 — 与用户列表同一列的口径。成品节点链到节点页定位那条成品，其余链到那台服务器的详情。
订阅链接 只读 — /sub/<订阅令牌>，下面按格式各给一个直达链接，打开即看到该格式的渲染结果。
账户到期 是 原值 改完按「保存到期」；须晚于当前时间。
备注 否 原值 改完按「保存备注」；只在控制台可见。
状态 — — 「停用用户」「启用用户」「删除用户」三个动作。

套餐管理

一张卡一份套餐。卡上：状态徽标（「生效中」或停服原因）、跟随的模板、各台服务器的服务器限额与已用、各授权体的限额与已用（撑破后另挂「超额」徽标）、账期与下次重置、有效期、套餐倍率、规则数与转发端口上限、追加流量与调账、续期快捷按钮（+N 天）。

动作 必填 默认 说明
新建套餐 — — 选模板后可「跟随模板」或「按模板填入」，也可选「自定义，不使用模板」。
编辑 — — 改名称、限额、倍率、限速、三项配额、授权形状、账期。跟随模板的套餐形状由模板持有，要改先「脱钩」。
脱钩 / 挂载到模板 / 存为模板 — — 脱钩后形状改为自定义；挂载后形状随模板变化；存为模板从这份套餐复制出一张新模板，原套餐不动。
调账 已用调整必填 整个套餐 如 -1G 扣减、500MB 补记，超出边界自动钳制；目标选某个授权体时同步它的额度。
追加流量 额外字节数必填 整个套餐 本账期有效，结算后清零；目标选某个授权体时只加宽它自己的限额。
暂停 / 恢复 — — 暂停保留实例、端口、凭据与规则，不改有效期与账期；恢复后沿用同一份实例与凭据。
重置 — — 冻结当前窗口的计费流水并开新账期，已用、追加流量、调账清零。不可撤销。
合并所选 N 份套餐 至少勾两份 — 先给预览：有效期取交集，有限额的额度与各份已用相加，限速与配额逐项收紧；有效期交集为空时合并不出来。
删除 — — 冻结最终计费流水后删除，覆盖的服务器授权随之失效。不可撤销。

可用服务器

可用的服务器由套餐决定，这里只维护单台服务器上的例外。列：服务器、授权来源、账期用量、剩余流量（套餐余量与服务器余量两个数，∞ 为不限）、生效能力。

字段 必填 默认 说明
入站协议 否 继承 每张部署一个三态：继承、强制开、强制关。只对本用户生效；上游授权已收窄时「强制开」实际仍关。
L7 协议拦截 否 继承 每种协议一个三态：继承、强制拦截、强制放行。协议有 TLS、HTTP、HTTP/2 (h2c)、SSH、SOCKS、BitTorrent。只作用于转发面：代理流量自首字节即加密，无从分类，拦截不限制代理面。
清空覆盖 — — 移除这台服务器上的全部例外，恢复继承服务器默认。

有例外的行带「已定制」徽标。可直连、可落地、可作入口、可作出口这几个角色属性按授权体授予，这里不改，要改去卖出这台服务器的那份套餐里改对应条目。

线路

这位用户名下跑着的全部线路实例：端口转发与链式代理两族一张表，与网络 › 线路的实例表是同一张（列、行操作与规则行的「线路」一格都相同），只是属主固定为这位用户、不再出现用户筛选。形态筛选、搜索词与页码写在地址栏里，刷新与回退仍在原处。这里点「新建规则」，表单预填这位用户。页签只对平台管理员出现。

公共节点

只读。列：代理、地址、来自套餐。在期套餐圈中的公共节点进入该用户的订阅与线路列表；它不改写凭据，也不统计流量。圈选与移除在「套餐管理」的套餐编辑器里做。

隧道设备

字段 必填 默认 说明
设备名称 是 无 「添加设备」或「改名」时填。
身份数 只读 — 展开看这台设备在各条线路上的身份。
启停 — 启用 停用或删除作用于这台设备的全部身份。

「添加设备」按钮只在 WireGuard 隧道这项可选功能开着时出现。设备归用户，一台设备在它持有的每条线路上共用同一组身份。

用量明细

按服务器与面列出累计用量：转发上行、转发下行、网卡流量。服务器被删除后，行上写「服务器已删除」与 id 前八位。

计费流水

字段 必填 默认 说明
套餐 · 账期起 · 账期止 只读 — 这一行冻结的是哪份套餐的哪个账期。
已用 · 限额 只读 — 结算那一刻的计费已用与限额。
原因 只读 — 结算、手动重置、删除套餐、套餐合并转出、到期、周期改配、所属主体冻结、套餐暂停、套餐未到生效期。
结算时间 只读 — 这一行写下的时刻。

同一页签下方是「条款版本」：价格、计价授权体或账期变化时留一版，合并也留一版；只保留当期与上一期账期的版本。每版列出套餐倍率与授权体倍率。

安全

字段 必填 默认 说明
凭证 只读 — 各协议的连接密钥与订阅令牌，默认遮盖，可不揭开直接复制。
轮换连接密钥 — — 重新生成全部连接密钥，旧值立即失效并同步到服务器；订阅链接不变，客户端要重新拉订阅。
重置订阅令牌 — — 旧订阅链接立即失效；连接密钥不变。
重置密码 — — 生成 12 位随机新密码，吊销该用户全部登录会话与API 令牌，移除已绑定的 TOTP 与通行密钥。不能对当前登录的自己做。
成品凭据 — — 用户持有成品节点实例时出现，逐个轮换；成品实例、端口和路径不变，手动导入的节点要重新导入。

注意

  • 新建用户时账户到期默认是下一个整点：不改就建出一个一小时内到期的账号。账户到期管接入寿命，套餐到期管卖出的范围，两者互不跟随。
  • 一个都不选模板，账号建成后没有任何服务器范围：用户能登录门户，订阅却是空的。
  • 登录密码明文只在交付包里出现一次，关掉弹窗后只能在「安全」页签重置。
  • 同一用户下，一台服务器在任意时刻至多被一份套餐覆盖；新套餐可以在旧套餐到期的那一刻接上。
  • 停用用户立即收回接入与转发，但不暂停套餐账期：结算日照常结算。平台管理员账号不能停用或删除，忘记密码用命令行 admin passwd 重置。
  • 联邦用户由接入方面板同步，不能在本面板单独删除；删除所属分销商会连带回收它的全部对象。
  • 没有任何套餐覆盖的流量不入账，记为未归账流量；它跨账期累加，不与套餐的超额相加。
