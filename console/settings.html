设置

设置

设置页分账户与安全、可选功能、网络与接入、备份与通知、系统与更新五个页签，API 令牌与两步验证在这里。

在哪里：系统 › 设置 › 账户与安全 / 可选功能 / 网络与接入 / 备份与通知 / 系统与更新

页签

  • 账户与安全：当前登录身份、修改口令、两步验证（TOTP）、通行密钥，以及API 令牌——每枚定用途、权限上限（只读、只读（含凭据）、读写、读写与高危四档）与有效期（7、30、90、365 天，默认 30）。
  • 可选功能：逐项开关分销商、联邦、域名与证书、自定义分流、WireGuard 隧道；另有「实验性特性」（显示高级参数）与「联邦用户」（是否展示联邦镜像用户）两个开关。
  • 网络与接入：发现令牌、对外下载基址、安装命令使用的控制面地址，以及出口探测目标。
  • 备份与通知：导出备份归档、R2 规则集分发、Telegram 通知。
  • 系统与更新：站点名称、计费时区、面板版本与升级、代理内核缓存，以及去许可证页的入口。

分销商管理员登录时没有页签，只看到账户与安全这一部分。

注意

  • 修改口令成功后该账号的全部会话失效，要重新登录。API 令牌的明文只在生成时显示一次；每个账号最多 20 枚有效令牌，权限上限之上的调用一律被拒。
  • 关闭一项可选功能会让对应入口与接口不可用，占用的数据冻结而不删除；已配置的分流方案、证书与 DNS 绑定关闭后继续生效。WireGuard 隧道例外：关闭即撤下，所有隧道立即断开，配置与设备数据保留。许可不含的那一项，开了也无效。
  • 控制面地址是服务器上的 agent 拨回面板用的地址，面板的证书只覆盖这些地址；列表不能删空，增删会立即重签证书，不中断已连接的服务器。
  • 备份归档含数据库快照与 CA 口令，等同面板全部机密。恢复或整机迁移：在目标机装好同版本面板、停掉服务后执行 weir-panel backup import 归档文件。
  • 计费时区决定自然月与周月账期的结算边界；改动只影响此后排定的边界，已排定的下一次结算不变。面板升级只替换面板本身并同步 agent 产物，各服务器上的 agent 还要在服务器列表单独推送。
