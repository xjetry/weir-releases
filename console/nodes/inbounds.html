协议配置

协议配置

协议配置定义一条协议线怎么听、用哪个内核、用什么安全模式；部署把它放到一台服务器上。

在哪里：网络 › 节点 › 协议配置

怎么用

  1. 在节点页点新建节点，选择协议并填写名称、默认端口和内核。
  2. 按所选安全模式填 SNI、密钥或证书；托管证书与手工证书二选一。
  3. 保存协议配置后选择服务器部署；逐机 TLS 模式要在各部署填写域名与证书。
  4. 修改已有配置时进入协议配置页签打开编辑；涉及协议材料、证书或归属变更时，核对影响确认后保存。

字段

字段 必填 默认 说明
名称 name 是 空 去除首尾空白后不能为空。
协议 protocol 是 初始为 VLESS 选择后按该协议重新限制参数、安全模式与内核。
内核 required_core 是 按可用候选选择 必须是所选协议可承载且当前允许使用的内核；机器也必须装有该内核。
默认端口 default_port 控制台必填 空 填 1 至 65535 的整数，作为部署表单预填值；不是所有机器都被强制改到此端口。
安全模式 security 按协议 初始为 reality 只能从所选协议允许的模式中选择。
SNI 按模式 空 表单里写作 server-name。reality 与 tls 托管证书模式必填，通配符证书要填具体一层域名；VLESS 无安全层时也要填；NAIVE 必填，逐机 TLS 时改由各部署填写。
证书 certificate_id TLS 托管模式是 未选 手工模式改填证书链与私钥；更换内联材料时两者必须一起换。
逐机 TLS tls_per_node 否 关闭 仅 NaïveProxy 支持；域名与托管证书移到每个部署，不存在配置级共用证书对。
协议参数 protocol_params、传输 transport 按协议 按表单预填 具体取值见协议字段参考；不能跨内核照搬参数。
订阅可见性 sub_visible 否 新建开启 控制订阅展示，关闭不等于删除部署。
出站地址族 egress_domain_strategy 否 PREFER_IPV4 只作用于域名目标；字面地址仍按它自己的地址族出站。

允许的内核按偏好顺序列出；实际候选还受许可与当前可用性约束：

协议值 可用内核 安全模式 说明
VLESS xray、sing-box none、reality、tls 传输与安全模式还须相容。
SHADOWSOCKS sing-box、xray 无独立安全模式 加密材料属于协议参数。
SNELL_V5 / SNELL_V6 sing-box 无独立安全模式 按各协议字段配置。
MIERU mbox 无独立安全模式 按协议字段配置。
ANYTLS sing-box reality、tls 不能关闭安全层。
NAIVE sing-box tls 支持逐机证书。
SOCKS5 sing-box、xray、mbox 无独立安全模式 无传输或安全配置层。

注意

  • 控制台要求默认端口非空且合法；数据字段中的零值表示未设置，不意味着表单允许留空保存。
  • 只改名称、默认端口或订阅可见性，不会重写协议材料；材料与证书改动会影响已有监听，应以确认框列出的部署为准。
  • TLS 材料缺失或超出有效期会让部署被扣发，保留“启用”并不能绕过证书校验。
  • 逐机 TLS 的域名与证书必须在部署侧成对提供；只保存协议配置尚不能让节点接收连接。
