套餐模板

套餐模板

套餐模板定义一类套餐卖什么、卖多久、算多少量，用户的套餐都从模板生成。

在哪里：运营 › 套餐模板

怎么用

  1. 点「新建模板」，填模板名称、有效时长与限额。
  2. 在授权一栏按「选择节点…」「选择线路…」打开选择框：每个授权类别选「全部」或逐个勾选，勾中的对象各成一个授权体。
  3. 需要时展开某个授权体的卡片，给它封顶、改倍率或改属性；单台服务器的额度在下面「添加服务器限额」里设。
  4. 按「创建」。新建用户或在「套餐管理」页签新建套餐时就能选这张模板。
  5. 以后编辑模板，所有跟随它的套餐随之更新。

字段

模板

字段 必填 默认 说明
模板名称 是 无 复制为新模板时必须与原模板不同。
说明 否 空 模板内部备注，不写入套餐。
有效时长 否 永不过期 天数，从套餐创建时刻起算；留空为永不过期，填写时须为正整数。
购买价格 否 0 用户自助购买该模板时从余额里扣多少点，非负整数。计费启用后才出现。
开放购买 否 关 允许用户在门户自助购买该模板。计费启用后才出现。
名称 否 空 由模板建出的套餐带的名字，如「月卡-A」。
限额 否 0（不限） 套餐整体每个账期的计费流量，支持 10G、500MB 写法；0 是不限额的唯一写法。
账期类型 是 自然月 自然月、周月（按起算日）、按天。按天时另填天数，默认 30。
套餐倍率 是 1 套餐最外层的那一乘，0.01 到 100，最多两位小数；1 即按实际计。
限速 否 不限 单位 Mbps。转发面全部生效；代理面只对能按用户分端口的协议生效，表单旁的提示按当前协议列出是哪几种。
每服务器规则数上限 否 不限制 空为不限制，0 为一条都不许建，-1 为明确不限。
每服务器转发端口数 否 不限制 口径同上；数的是转发监听端口，不含代理入站。
每服务器隧道设备数 否 3 空为默认 3，0 为禁止，-1 为不限。数的是同一台服务器上的设备，不是用户的设备总数。

授权类别

选择框分两个分区：节点分区放可连接的对象，线路分区放可用于转发的对象。同一台服务器在两个分区各出现一次，是两个互不相关的授权体。

类别 分区 卖的是什么 可设
服务器代理 节点 整台服务器的协议配置作为一个授权体；之后新建的协议配置自动在内。 倍率、可直连、可落地；额度见服务器限额
成品节点 节点 成品节点整体加入订阅；未绑定出口的草稿不在列。 实际流量上限、倍率、可直连、可落地
公共节点 节点 按导入的凭据进入持有者的订阅，不参与转发。 可直连、可落地；恒不计量
单服务器线路 线路 这台服务器作为一跳被使用的授权，与它的协议配置各算各的。 倍率、可作入口、可作出口；额度见服务器限额
组合线路 线路 组合线路与隧道线路整条加入，成员服务器随它附带，不是独立授权。 实际流量上限、倍率、可作入口、可作出口

每一类三选一：不卖、全部、指定。「全部」随该类名册自动扩展，以后新增的也算，但不含联邦镜像，镜像要逐个勾选；分销商管理员登录时「全部」以分销授权的服务器为界。「指定」只卖此刻勾中的那些。

配方条目

每个被点名的授权体是一行配方条目，条目的种类与类别对应如下：

条目种类 显示名 所属类别
SERVER_PROXY 服务器代理 服务器代理
FORWARD_PRODUCT 成品节点 成品节点
PUBLIC_PROXY 公共节点 公共节点
FORWARD_NODE 单服务器线路 单服务器线路
COMPOSITE_NODE 组合线路 组合线路
ACCESS_ENDPOINT 隧道 组合线路

「指定」之下条目是成员；「全部」之下条目是例外，必须至少做一件事：排除、封顶、改倍率或改属性。

字段 必填 默认 说明
排除 否 否 只在「全部」之下出现，把这个授权体从整卖名册里拿掉。
实际流量上限 否 不限 这个授权体自己的天花板；只有成品节点与组合线路两类有。
授权体倍率 否 继承 替换对象自身的那一乘，留空即继承对象默认。卡片上同时列出对象默认、套餐倍率与实际计费的乘积。公共节点没有这一项。
属性 否 继承 每一位三态：继承、允许、禁止。节点分区的类别可改可直连、可落地；线路分区的类别可改可作入口、可作出口。成品节点只能收窄成品本身已开的位。

服务器限额

字段 必填 默认 说明
服务器 是 无 选一台服务器，一台一行。
额度 是 无 如 30G。这台服务器上全部授权体共燃的实际流量额度。

不设时，该服务器上的授权体不单独设上限。

模板列表

列：名称、范围、限额、计费倍率、周期、有效期，计费启用时另有价格。名称旁的「已停用」表示模板不出现在新建套餐的下拉里；「引用失效」表示配方点名的对象已删除或无权访问，修好之前不能用它新建套餐。行上动作：复制、编辑、停用 / 启用、删除。

注意

  • 倍率最小 0.01、最大 100，不能为 0：零倍率让每笔扣量都是零，有限额度永远用不完，等于不限额。不限额只有一种写法，限额填 0。
  • 实际计费的倍率是授权体倍率乘套餐倍率；两层分开填，空着的那一层继承。
  • 同一用户下，一台服务器在任意时刻至多被一份套餐覆盖；前一份到期的那一刻接上后一份不算重叠。编辑模板时若某个跟随套餐会与同一用户的另一份套餐撞上，保存被拒，并列出占用方；「让位并强制保存」后重叠交由读侧仲裁，覆盖范围窄的那份胜出，不撤销任何一方。
  • 每一类都选「全部」、限额为 0、有效时长留空的模板没有成本边界；用它建套餐时要勾选确认才能提交。
  • 停用模板只把它从下拉里藏起来，已由它建出的套餐照常工作。删除模板时要逐字输入名称，跟随它的套餐转为自定义。
  • 分销商模板不承载公共节点；从含公共节点的套餐存为分销商模板时，那几行不随模板，要由平台管理员在套餐里另行圈选。
