地址与域名

服务器地址

一台服务器交给别人拨的地址只有一张表，每行是一个 IP 或域名，带代理入口与转发入口两个位。

代理入口给客户端连接（订阅线路、隧道设备配置、联邦导出），转发入口给端口转发的入口与其它服务器拨到本机。域名绑定保存后自动成为表里的一行。

在哪里：网络 › 服务器 › 详情 › 配置 › 服务器地址

怎么用

  1. 看表：每行显示地址、地址族、来源、两个位的开关和「生效」徽章；两个位都关的行标「未作入口」。上报行由 agent 维护，按地址族各一行，两位缺省全开。
  2. 添加：填 IP 或域名，勾选两个位（缺省全开），点「添加」。上报中还没列入的地址可直接点击加为手工行。
  3. 改位与排序：勾选或取消某行的位、拖动改顺序，然后「保存地址」。保存一次提交全部行的位与顺序。草稿会换掉某族的客户端连接地址时先弹确认，核对改动前后再确认；只动转发位或顺序不改客户端连接地址时直接保存。
  4. 域名绑定：在同页 DNS 管理保存绑定后，这个名字自动成为来源「域名绑定」的行，两位缺省关。保存完整成功后面板问一次要不要把它作为代理入口，确认即开这一行的代理位并排到表首。
  5. 探测：卡头「探测公网 IP」让 agent 重新采集公网地址，上报行随之更新，不产生草稿。

字段

字段 必填 默认 说明
地址 address 添加时是 无 IPv4、IPv6 或域名；已在表里的地址不能再添加。先手工添加、后来又在 DNS 管理里绑到本机的名字会有两行（手工与域名绑定），它能服务的族按两行的记录合并算。
地址族 family 只读 按地址判 IPv4 / IPv6 / 域名。域名能服务哪些族由它的解析记录决定。
来源 origin 只读 按写入者 上报（agent 上报的公网地址）、agent 声明、上游（联邦镜像同步）、域名绑定（DNS 管理保存的名字）、手工（本页添加）。
代理入口 proxy_entry 否 上报与手工行开，域名绑定行关 开着的行按表序第一条给订阅线路、隧道设备配置与联邦导出作客户端连接地址。
转发入口 forward_entry 否 上报与手工行开，域名绑定行关 开着的行按表序第一条给端口转发规则作入口，也是其它服务器拨到本机的候选；被线路钉住的行不能关。经 CDN 代理的域名绑定行不能开。
生效 effective 只读 服务端算出 「代理 v4 / v6」「转发 v4 / v6」四枚徽章各落在恰好一行上；没有一行开位的族没有徽章。
在场 present 只读 来源决定 上报来源撤回后行仍保留，标「已不在上报中」，不再生效；再次上报后恢复同一行，位与顺序不重置。
解析记录 records_v4 / records_v6 只读 面板定时解析 非托管域名行由面板每 5 分钟解析一次，域名绑定行的记录就是绑定上的 A / AAAA；行标签里的括号列出它们。

生效规则

每个地址族、每个位各取表序第一条「开了该位、来源在场、能服务该族」的行。字面量只服务自己的族；域名看记录：还没解析过的名字两族都算，解析到没有记录的族不算。关掉服务器 IPv6 后，v6 字面量不再可用，也不再有 v6 的生效行。表序、位、上报撤回都会改生效行，保存前的确认框把改动前后的客户端连接地址摊开给你看。

概览页签的「地址」卡按四格摘要这四个生效行，没有的族写「无」；镜像页签同一组字段。

域名

  • 行标签写成 名字 (记录)：有记录时括号里列出 A 与 AAAA，如 a.example.com (1.1.1.1, ::1)；还没解析过显示 (解析中)，名字不存在或解析到没有记录显示 (无记录)；最近一次解析失败但有旧答案时追加「解析失败，沿用上次答案」。
  • 托管域名（DNS 管理里的绑定）的记录由面板写，不再解析；非托管域名由面板定时解析。解析结果只决定这个名字能服务哪些族，不改客户端拿到的东西——客户端连接的是域名本身。
  • 把域名作为代理入口时，订阅与设备配置里出现的是域名；端口转发入口与服务器间拨号仍按转发入口位的行。

注意

  • 经 CDN 代理（小黄云）的域名绑定行不承载原始 TCP / UDP，不能作转发入口，开关置灰并说明原因。
  • 被线路钉住的行不能关转发入口，也不能删除；按钮置灰并提示引用数，先在线路里改用其它地址。排序不受钉住限制。
  • 上报行、域名绑定行与上游行由来源维护，不能删除；不用时关掉它的两个位。只有手工行可删。
  • 上游镜像服务器的表由上游同步，本地只读。
  • 表里没有一行开着转发入口时，这台服务器不能作为被拨目标；没有一行开着代理入口时，它上面的线路进不了订阅。
  • 保存期间服务端多了一行（新上报的族、新保存的绑定），保存会被拒并提示重载；重载后再改。

升级后对照

  • 旧「对外 v4 / v6」与旧「对外域名」= 现在代理入口位的生效行。选中过的域名迁移成一条开着代理入口位、排在表首的域名绑定行；手工填的字面量成为开着两个位的手工行；跟随上报的槽不生成行，上报行本来就开着两个位。
  • 旧「转发 IP」表 = 现在转发入口位。原来启用的行开着转发入口，原来停用的行关着；线路钉住的行不变。
  • 经 CDN 代理的域名原来同时给端口转发作入口；迁移后端口转发入口改为表里第一条开着转发入口位的行（通常是上报地址），订阅仍是域名。
  • 面板启动日志里的迁移回执给出三项计数：默认拨号地址因置顶改变的机器数、上报行重新开位的机器数、镜像上曾选中的域名被放弃的机器数。
