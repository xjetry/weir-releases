地址与域名

地址与域名

一台服务器有对外、互联、机器三组地址，各自给不同的连接方用；域名绑定让地址跟着机器走。

在哪里：网络 › 服务器 › 详情 › 配置

怎么用

  1. 在配置页的对外地址选择自动、上报地址、绑定域名或自定义地址，保存前核对确认框。
  2. 需要机器间使用另一地址时，进入详情 › 线路，填写互联地址；不填则随机器公网地址。
  3. 在配置页的域名绑定选择托管域、前缀与地址，核对冲突和记录删除提示后保存。
  4. 地址动态变化时开启动态 DNS 跟随，选择已有记录的地址族；查看检查时间和失败明细。

字段

字段 必填 默认 说明
对外地址策略 public_host_v4_policy / public_host_v6_policy 按族选择 编辑时为当前值 客户端订阅与转发入口使用的地址；可选绑定域名。
机器地址 manual_v4 / manual_v6 否 空时回落上报地址 手工指定机器地址；与对外选中的域名分开保存。
上报地址 reported_ips 只读 机器上报 自动地址的来源，不代表已创建 DNS 记录。
互联地址 relay_host_v4 / relay_host_v6 否 随机器公网地址 多跳转发拨下一跳用；优先采用手工机器地址，否则取对应族首个上报地址，支持域名。
托管域与前缀 建绑定时是 无 前缀不能填 @；选择器只列凭据有效的托管域。
绑定地址 ipv4 / ipv6 至少一族 可探测预填 可选上报地址或手填；两族都空不能保存。
动态跟随 ddns_enabled 否 按当前绑定 开启后按 ddns_interval_min 的周期取机器观测到的公网地址。
跟随族 ddns_v4 / ddns_v6 开启时至少一族 按当前绑定 只能选择绑定已有记录的族。

注意

  • 对外地址给客户端，互联地址给下一跳拨号，机器地址供机器间回落与地址跟随等用途。选了对外域名，不会把机器地址变成这个域名。
  • 每个地址槽只接受对应族的字面地址或域名。存量错族值会被当作空，页面标为未生效。
  • 动态 DNS 跟随机器现场探测或最近上报的地址，不跟手工固定的对外地址；手工填值不等于关闭动态跟随。
  • 删除绑定或去掉某族时，面板会删除它拥有的提供商记录；发现来的、未归绑定所有的记录不会删。必须读保存回执，失败族并不因页面保存完成而自动成功。
  • 上游镜像服务器的地址由上游同步，本地只读。
