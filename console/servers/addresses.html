地址与域名

地址与域名

对外地址供客户端连接，转发 IP 供其它机器拨到本机；两者独立配置。域名绑定让 DNS 记录跟着机器上报的地址走。

在哪里：网络 › 服务器 › 详情 › 配置

怎么用

  1. 在配置页的对外地址里，有绑定域名时先在「对外域名」行选用或不用域名。没选域名时，IPv4 / IPv6 两槽可选自动、上报地址或自定义；选了域名后两槽隐藏，客户端连接域名。概览以「上报地址」只读行显示 agent 上报值。保存前核对确认框。卡头「探测公网 IP」让 agent 重新采集上报地址。
  2. 进入详情 › 线路的转发 IP 表，添加机器间可达的 IP 或域名，并按默认选用顺序排列。
  3. 在配置页的域名绑定选择托管域、前缀与地址，核对冲突和记录删除提示后保存。
  4. 地址动态变化时开启动态 DNS 跟随，选择已有记录的地址族；查看检查时间和失败明细。

字段

字段 必填 默认 说明
对外域名 public_dns_binding_id 否 不用域名 选中后订阅线路与转发入口双栈只出该域名；候选来自本页 DNS 管理里的绑定。
地址槽 manual_v4 / manual_v6 否 空时跟随上报地址（AUTO） 没选域名时显示，可填 IP 或域名作为客户端连接地址；选了域名时隐藏，机器地址只用于来源围栏、地址认领与联邦导出。不参与服务器间拨号。
上报地址 reported_ips 只读 机器上报 AUTO 的来源，也是动态 DNS 跟随的来源；各槽 AUTO 选项的标签里带出当前值。不代表已创建 DNS 记录。
转发 IP dial_addresses 机器被拨时须有可用条目 第一条符合当前路径条件的可用条目 机器间拨号的唯一地址来源，支持 IPv4、IPv6 和域名；不回落到对外地址或绑定域名。
托管域与前缀 建绑定时是 无 前缀不能填 @；选择器只列凭据有效的托管域。
绑定地址 ipv4 / ipv6 至少一族 可探测预填 可选上报地址或手填；两族都空不能保存。选中为对外域名后，这两条记录就是机器各族的对外字面量：转发入口、订阅线路与联邦导出按它们判族，没有记录的族不对外提供，不回落到上报地址。
动态跟随 ddns_enabled 否 按当前绑定 开启后按 ddns_interval_min 的周期取机器观测到的公网地址。
跟随族 ddns_v4 / ddns_v6 开启时至少一族 按当前绑定 只能选择绑定已有记录的族。

转发 IP

表内每行显示地址、地址族和来源。来源标签为「上报」「agent 声明」「上游」「手工」。上报来源按地址族各维护一行；同族地址改变时更新原行，不换身份。其它已上报但未入表的地址可点击添加为手工行。

四种操作：

  • 添加：填写可达的 IP 或域名，新增手工行；新行排在表尾。
  • 排序：拖动行或使用排序按钮。新建路径默认选第一条符合条件的可用行，已保存路径保持原来的钉住行。
  • 启用 / 禁用：禁用后不再用于拨号，但地址仍属于这台服务器，登记和落地匹配仍识别它。
  • 删除：只允许删除手工行；来源行不能删除，可禁用。

被线路钉住的行不能禁用或删除，对应按钮置灰并提示引用数量；先在线路中改用其它转发 IP 或删除引用。排序不受钉住限制。上游镜像服务器的表由上游同步，本地只读。

来源撤回后行仍保留，标为「已不在上报中」，不参与拨号；钉住它的路径会扣发，不自动换地址。该来源再次上报后恢复同一行，启用状态与顺序不被重置。想固定使用另一个地址，应添加手工行并在线路中选择它。

注意

  • 修改对外域名、地址槽或绑定域名，不会替转发 IP 表补地址。表内没有可用条目时，这台机器不能作为被拨目标。
  • 地址槽仍按 IPv4 / IPv6 分族填写；转发 IP 行自身带地址族，不再是一族只能填一个互联地址。
  • 动态 DNS 跟随机器现场探测或最近上报的地址，不跟手工固定的对外地址；手工填值不等于关闭动态跟随。
  • 删除绑定或去掉某族时，面板会删除它拥有的提供商记录；发现来的、未归绑定所有的记录不会删。必须读保存回执，失败族并不因页面保存完成而自动成功。
  • 上游镜像服务器的地址由上游同步，本地只读。
