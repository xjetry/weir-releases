接入与安装命令

接入一台服务器有两条路：拿安装命令去装，或让已装好 agent 的机器凭发现令牌自己找上门。

在哪里：网络 › 服务器 › 新建

怎么用

  1. 在新增页确认安装程序已托管；未准备好时先完成页面上的托管操作。
  2. 单台接入填服务器名称并创建；批量接入生成发现令牌，取同一条安装命令到多台机器执行。
  3. 按登录权限选择安装命令形态，复制命令到目标机器运行；有效期以页面显示为准。
  4. 等待该机器在线，再配置地址、安装代理内核和创建节点。命令丢失或过期时，到原服务器详情的概览重新生成。

字段

字段 必填 默认 说明
服务器名称 name 单台接入是 空 不能与已有服务器重名；批量接入由面板分配名称。
安装命令形态 否 自动提权 已以超级用户登录时可切换为不提权形态，不会另建服务器。
接入令牌 只读凭据 创建时签发 单台接入绑定到指定服务器行；明文只显示一次。
发现令牌 批量接入需要 未生成 有效期内可供多台机器重复使用；重新生成会使旧令牌失效。
机器指纹 machine_fingerprint 只读 未绑定为空 识别当前绑定的机器；证书续期不改变指纹。

新增页的两个页签是批量接入、单台接入。已存在的服务器在详情 › 概览查看接入令牌，在详情 › 危险区处理解绑。

注意

  • 创建服务器行不等于机器已经接入；pending 表示还在等机器，active 才表示已经绑定。
  • 安装命令含凭据，离开或刷新页面后不能取回同一份明文；过期后为原行重新签发，不要再创建一行。
  • 已解绑的 retired 行保留原引用，使用为它签发的安装命令重新绑定。解绑不是删除。
  • 刚上线且没有部署是正常状态；先确认在线与机器指纹，再做后续配置。
