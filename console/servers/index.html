服务器

服务器

服务器页管你的每一台机器：接入、地址、能力位、上面跑着什么、以及它的运维命令。

在哪里：网络 › 服务器

怎么用

  1. 在列表查看在线状态、来源与端口余量；新增机器进入接入页。
  2. 点进服务器详情，在概览核对绑定、版本与应用进度。
  3. 在配置页改端口段、对外地址与计费；在节点页管部署，在线路页管转发能力与互联。
  4. 运维动作到命令页，核日志、核配置与日志级别到诊断页；解绑或删除前到危险区核对影响。

字段

字段 必填 默认 说明
名称 name 创建时是 无 显示名称；重名会被拒绝。
状态 status 只读 待接入 pending 等机器、active 已绑定、retired 已解绑。
在线 online 只读 按上报 控制连接已注册，且最近消息仍在心跳窗口内。
端口段 port_range 按需设置 当前值 代理与转发共用的监听端口池；保存时已占端口会自动并入。
端口容量 port_capacity 只读 按占用计算 total 是池大小，used 包括池外占用，free 是可自动分配余量。
推送与应用代数 只读 未报告为零 push_generation 是面板推送计数；agent_applied_generation 是机器已持久化的代数。
收敛与平面状态 只读 未报告为空 agent_converged_generation 与 agent_planes 说明各平面是否实际完成。
停用 disabled 只读派生 按当前状态 来自本地停用、上游撤下或已解绑，不能一概当成本地开关。

详情页签依次为概览、节点、线路、授权、配置、隧道、命令、诊断、镜像、危险区。上游镜像服务器没有隧道、命令与诊断页签，镜像页签只在镜像服务器且开启联邦时出现；隧道页签在这台服务器启用隧道、或仍有遗留入口要清退时出现。

节点页签每张部署带一列「URI」：平台管理员本人订阅里这张部署的线路，IPv4 与 IPv6 各一条，可直接复制；本人订阅里没有这条线路、或线路被扣发时，这一格写原因。列只对平台管理员出现，与节点页同一口径。

诊断

在哪里：网络 › 服务器 › 服务器详情 › 诊断

  • 核日志：从这台服务器的 agent 现取日志，可选级别与行数。单次上限 1000 行 / 256 KB，超出会在末尾标注截断。
  • 核配置：选择核，现取该核当前落盘的 config.json 原文，上限 512 KB，超出会截断。候选来自服务器上报的核版本；尚未上报时提供默认核清单。
  • 日志级别：与核配置共用所选核，可改这个核的日志级别，默认 warn。保存后该核会重启，存量连接瞬断；可在上方核日志观察效果。
  • 日志与配置不在面板留存；服务器离线时三个分区都会提示，不能拉取日志、拉取配置或保存日志级别。

授权页签的「已用 / 限额」显示该套餐在本服务器本账期的实际流量，以及该套餐对本服务器的限额；没有服务器限额时显示 ∞，没有本服务器用量时显示 0 B。进度条按这两个数计算，下方「套餐」一行保留套餐整体的计费用量与限额。

注意

  • 在线只证明机器仍在回应，不证明每个监听都能用。已应用代数非零且等于推送代数后，还要看收敛代数与平面报告。
  • 端口余量直接读 free，不能用 total - used 计算：池外占用与池内保留端口的计数口径不同。
  • 清零流量只清这台服务器的控制台展示，不改变用户计费和套餐已用。
  • 解绑保留服务器行及全部引用；删除移除这台服务器上的部署，并整条删除包含它的组合线路与引用它的转发规则（组合里的其他服务器保留），不是同一个动作。
