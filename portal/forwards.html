转发

转发

转发页让你用套餐授权给你的线路自建端口转发或链式代理。

在哪里：转发 › 全部 / 透明线路 / 链式线路

一条转发规则声明自己的路径与目标：客户端连到路径第一段的监听端口，流量按段经过你选的线路，最后到目标。路径里每一段都按「透传」原样转走时，规则是端口转发，列表上的形态是「透明线路」；路径里有一段按「协议」经过一张协议面时，规则是链式代理，形态是「链式线路」，到了链尾再出站。能用哪些线路、每条能站在哪一位，先看线路页。

怎么用

  1. 点「新建规则」。在「规则」块填名称，选协议（TCP、UDP 或 TCP+UDP）。
  2. 在「路径」块点「添加一段」，为每一段选类别（单节点线路、组合线路或隧道）和对象；选好对象后再选这一段的经过方式：透传或协议。段下方写出这一段在路径里的位置（入口、中转、出口、协议跳）。可用上移、下移调整顺序。路径摘要按「名字 ×倍率 → 目标」显示，段倍率之外套餐计费倍率另行相乘。
  3. 在「目标」块定流量的终点。路径里还没有协议跳时，二选一：「自定义地址」填地址与端口，也可以直接粘一条代理 URI，解析后存进你的落地清单并选作目标；「落地节点」从你可作落地的节点里选。点「测试」从最后一段的出网节点探一次目标通不通。
  4. 路径已越过协议跳时，目标只能是这条链收尾的那个对象：一个落地节点、一个成品节点，或在协议跳就是最后一段时从那个节点直接出网；「自定义地址」一档改为选一条落地 URI。
  5. 「监听端口」留空或填 0 由面板自动分配。需要时展开「高级选项」改连接池大小。
  6. 右栏「转发摘要」显示路径；编辑已有规则时还显示「你连接的地址」。点「创建规则」保存，回到列表。

字段

字段 必填 默认 说明
名称 是 无 规则自己的名字，显示在列表与节点页的转发节点里。
协议 是 TCP TCP、UDP 或 TCP+UDP。路径一个透传跳都没有时不问这一格，由链入口那张面决定收得下什么。
路径 · 类别与对象 是 无 至少一段。隧道只能作第一段。
路径 · 经过方式 是 随所选对象 透传：原样转走，不重新拨号。协议：在那张面上以你的身份重新拨号；它后面再接一段时，这一段的位置就从出口变成链式中转。
目标 是 无 自定义地址（地址与端口）或落地节点；越过协议跳后见上文第 4 步。
监听端口 否 自动分配 客户端连的端口，只作用在第一段。编辑时留空或 0 表示保持现端口，不是重新分配。
连接池大小 否 4 预先连到落地的连接数，非负整数。SSH、SMTP 这类一连上就由对端先发招呼的服务填 0。

列表与操作

列表列出名称、入口节点、形态、入口 / 出口地址、路径、协议、订阅 URI、流量与状态。点名称进详情页，上面有「入口（复制给客户端）」的分享链接、逐跳原因、流量与创建时间。行尾的操作：

  • 测试：探一次整条规则，结果写「通」或「不通」及原因。
  • 编辑、停用 / 启用、删除规则。删除后转发立即中断。
  • 轮换凭证：只在带链尾的链式线路上出现。轮换后旧凭证立即失效，订阅需重新拉取；你的普通凭证与直连节点不受影响。

状态徽章五档：「运行中」「部分未生效」（有一跳没在跑）、「未生效」（整条路断了）、「已停止」（权限收紧把规则停住，悬停看是哪个授权缺了）、「已停用」（你自己停的）。

注意

  • 规则只能用套餐授权给你的线路；套餐收回某条线路的授权后，经过它的规则显示「已停止」，悬停徽章看是哪个授权缺了。
  • 以隧道为第一段时，隧道出口后可直连目标，也可再接几段中转；出口尚未就绪时规则创建成功但暂不生效，列表顶部会带出这条提示。这里建的是普通转发规则，与线路页隧道线路自带的专属出口互不相干。
  • 套餐隐藏了组合线路的成员时，列表与详情的路径只写「线路已隐藏」。
  • 「落地节点」的候选来自节点页开了「落地」用途的节点；候选空着时可以在目标框里直接粘贴代理 URI，或先去节点页「添加节点」。
