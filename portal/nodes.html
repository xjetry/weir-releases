节点

节点

节点页列出你能用的全部节点，按来源分成套餐节点、转发节点、公共节点和自建节点。

在哪里：节点 › 全部 / 套餐节点 / 转发节点 / 公共节点 / 自建节点

一个节点是一条能连的协议线。同一个名字下常有好几个节点（同一处的不同协议或不同种类），页面把它们归在一个名字下，每个节点各自复制自己的链接。额度不在这一页，在首页每份套餐的展开区里；这里只把用尽与被拒画成行上的徽章。

怎么用

  1. 用页顶的来源页签筛选：「全部」不筛，其余四个各看一种来源；页签上的数字是这一来源的节点数。
  2. 要把一个节点手动放进客户端，点行上的「复制」拿到分享链接；有 IPv6 地址的行旁边多一个「IPv6」。要整批导入，去订阅页取订阅链接，不必逐条复制。
  3. 要加自己已有的节点，点右上角「添加节点」，把分享链接粘进去（每行一条），选好用途，点「解析」。预览逐行说明这一行是什么、会落到哪里：「重复」表示你已有同协议、同地址、同端口的一条，保存只把用途并进那一条；「无法解析」的行不能勾选，改好文本再解析。确认后点「保存」，弹窗下方给出「批次结果」，弹窗不关，可以接着粘下一批。
  4. 自建节点的用途随时可改：行上的「订阅」「落地」两颗芯片各是一个开关。「改名」只改显示名，同步更新复制出的链接与订阅里的名字，不改连接参数。

四种来源

来源 从哪来 你能做什么
套餐节点 套餐授权给你的协议线，含套餐里的成品节点 复制链接；成品节点可「删除」撤销这份分配，节点立即从订阅消失，恢复需管理员重新分配
转发节点 你自己在转发页建的规则生成的线，按规则自己的名字成组 复制链接；改动去转发页
公共节点 平台按套餐分配的共享线路，不计流量 复制链接；不能自行删除，开着分流时可「在订阅里隐藏…」，跳到分流方案按行隐藏
自建节点 你自己粘贴进来的分享链接，不计流量 复制、改名、删除，切换「订阅」「落地」两个用途

每行标出协议、地址与种类：直连、中转、链式、中转链式或隧道。公共节点与自建节点都是你或平台给的一条链接，面板不在它前面接转发段，所以一律是直连。

字段

「添加节点」弹窗：

字段 必填 默认 说明
URI（每行一条） 是 无 分享链接，每行一条。支持的方案：anytls、hy2、hy3、mierus、naive+https、snell、socks、socks5、ss、trojan、tuic、vless、vmess；Surge 风格的 名称 = snell, host, port, psk = … 也认。
用途 · 订阅 否 开 开着时这一行进你的订阅。
用途 · 落地 否 开 开着时这一行可作你转发规则的落地。

「修改节点名称」弹窗只有一个字段：节点名称，必填，最多 128 个字符。

注意

  • 去重按协议、地址、端口三样：重复粘贴同一条只合并用途，不会多存一行，也不会替换原文——这一行可能已被你的转发规则拿来当落地，替换原文等于换掉拨号凭据。要换凭据，先删除再重新添加。
  • 自建节点存在面板上，而不是浏览器里：订阅链接由面板渲染，任何设备、任何客户端拉订阅时面板都要读得到这些行；勾了「落地」的行，转发那一侧也要从面板取到它。
  • 删除一个自建节点时，以它为落地的转发规则立即失效。
  • 一条线此刻不在服务时，行照样列着，协议与地址压淡，原因整句写在行下。套餐节点这时可能仍带着能复制、却拨不通的链接，先看原因再排查客户端。公共节点在套餐暂停或未开始时不在订阅里，行上没有复制按钮。
  • 粘进来的链接若正是本面板某个节点的分享行，行上标「本面板节点」（地址已变时标「本面板节点旧地址」），它不再作落地候选；建转发时请直接选那个节点。
  • 套餐里有 WireGuard 隧道时，页面下方多出「接入设备」一节，列出你的设备、它在哪条隧道线路上有身份、身份数与是否启用；隧道成品节点以卡片列出。设备的增删在订阅页。
