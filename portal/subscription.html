订阅

订阅

订阅页给你订阅链接，按客户端选格式，并决定哪些节点进订阅。

在哪里：订阅 › 你的客户端

订阅链接是一条普通的 https 地址，客户端定期拉它，拿到的是面板按你此刻的套餐、节点与分流方案现场渲染的配置。所以节点增减、套餐变化不用重新导入，客户端下次更新订阅就跟上了。页面的顺序是：先选客户端，再复制链接或一键导入。

怎么用

  1. 在「你的客户端」一排里点你用的客户端。每块写着「支持分流」或「仅节点列表」。
  2. 下方面板以客户端名为标题，标题右侧写这份订阅正文里有几个代理、省略了几条线路。面板里先是一句这个客户端的说明，然后是「订阅链接」与复制按钮。
  3. 有一键导入的客户端，点「导入 …」按钮把链接直接交给已安装的客户端；没有的，按钮写「一键导入（该客户端无 deep link）」且不可点，复制链接后在客户端里手动添加。各客户端的步骤见客户端导入。
  4. 支持分流的客户端可在「分流方案」里选一份方案，链接随之带上它；不选就是「默认（仅节点列表）」。方案只改变这一条链接的渲染结果，每个客户端各记各的选择。点「去分流」编辑方案。
  5. 想看客户端会拿到什么，点「预览订阅内容」。

字段

字段 必填 默认 说明
客户端 是 第一个（mihomo / Clash） 决定链接的格式。七个客户端与格式的对应见客户端导入。
格式 否 Base64 只在「通用 / 其他」下出现：Base64 或原始 URI。
分流方案 否 默认（仅节点列表） 只对 mihomo / Clash、Stash、Surge、sing-box 出现。
接入设备 否 默认（最早启用的设备） 只在你有 WireGuard 隧道时出现在页顶。下方所有复制链接与导入按钮都跟随它；指定设备后用它自己的各个身份，不借用别的设备的密钥。

这份订阅里有什么

面板下方常驻一段，说这个客户端的订阅正文含几个代理，以及两类拿不到或跑不通的线：

  • 未写入正文：这一条不在这份订阅里。原因要么是这个客户端的格式装不下它的协议，要么是这条线此刻不在服务、材料被撤下了。前者换一个客户端就能拿到，后者等它恢复或联系管理员。
  • 写进了正文却不在服务：客户端里看得见这个节点，但此刻拨不通，原因随行写出。

换一个分流方案，这几个数会一起变：方案可以把某些行藏起来。

页面下方还有两块：公共节点清单（平台分配的共享线路，在服务的已在你的订阅里，不在服务的此刻不在、原因消除后自动回来），以及有 WireGuard 隧道时的「接入设备」。在接入设备里可以「添加设备」、改名、停用、删除；展开一台设备逐个下载它各身份的配置，并查看 IPv4 与 IPv6 隧道地址；入口不承载 IPv6 时只显示 IPv4。点「用于订阅链接」让上方的链接指向这台设备。

注意

  • 订阅链接本身就是凭据：拿到链接的人就能拉到你的节点。泄露后去账户页「订阅安全」重置订阅令牌，旧链接立即失效，所有已导入的客户端要重新导入。
  • 「轮换连接密钥」也在账户页：它换掉全部协议凭证，订阅链接不变，但客户端要重新拉一次订阅才能连上。
  • 选中的分流方案被删、或选中的设备被停用后，面板不再给出链接与导入按钮，改为一句提示请你重新选：带着它的链接会指向一个不存在的对象，方案缺席时订阅地址返回 404，设备缺席时隧道被扣下。
  • 页顶出现「暂无可订阅的线路」时，去节点页看套餐授权给你的线各自进不进订阅：可能一条都没被授权，也可能授权了的都只作落地。
  • 客户端会在订阅界面显示的已用流量、总量、到期时间，以及更新间隔与订阅名，由面板随订阅一起给出；完整清单见订阅格式与响应头。
